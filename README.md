# Textures

## Project Details

Textures is an online platform to find and purchase texture images. The project is built using Next.js and deployed on Vercel.

## Deployment Instructions

To deploy this project on Vercel, follow these steps:

1. Sign in to your Vercel account.
2. Create a new project and import the repository from GitHub.
3. Vercel will automatically detect the Next.js project and configure the deployment settings.
4. Click "Deploy" to deploy the project.

## Project Structure

- `pages/`: Contains the Next.js pages for the project.
- `public/images/`: Contains the image data used in the project.
- `styles/`: Contains the CSS styles for the project.
- `vercel.json`: Configuration file for Vercel deployment.
